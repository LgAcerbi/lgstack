# Prove it works

A claim that something works needs evidence you produced in this session.

- "It compiles" and "the types check" are not evidence that behavior is right.
- Run the tests, the type checker and the linter, and report their actual output.
- For UI or runtime behavior, run the real thing (dev server, script, browser) and observe it.
- If you could not verify something, say so plainly. Never imply a check ran when it did not.
