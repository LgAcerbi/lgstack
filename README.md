# lgstack

My Claude Code plugins for rigorous, AI-assisted development.

## Install

```
/plugin marketplace add LgAcerbi/lgstack
/plugin install work@lgstack
```

## Plugins

| Plugin | What it does |
| --- | --- |
| [work](work/README.md) | A staged, approval-gated workflow for TypeScript/web development. Run `/work <request>` and it picks the route: kickoff, plan, design, build test-first, then vet and attack the diff. |
